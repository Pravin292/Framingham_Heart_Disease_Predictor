# 🫀 Framingham Heart Disease Predictor

A medical diagnostic application targeting 10-year risk of coronary heart disease (CHD). Based on the historic Framingham Heart Study, this project implements a robust Logistic Regression pipeline for clinical risk assessment.

---

## 🚀 Key Features
- 🔹 **Clinical Data Analytics**: Derived from real-world medical data points (Cholesterol, BP, Glucose).
- 🔹 **Probabilistic Evaluation**: Provides a percentage-based risk score for coronary events.
- 🔹 **Feature Importance**: Visual insights into which health factors contribute most to cardiac risk.
- 🔹 **Lightweight Implementation**: Optimized for quick deployment and execution.

## 🧬 Technical Stack
- **Models**: Logistic Regression
- **Data**: Framingham Dataset
- **Evaluation**: ROC-AUC, Precision/Recall Analysis
- **Framework**: Python (Scikit-Learn)

## 🛠️ Installation

git clone https://github.com/Pravin292/Framingham_Heart_Disease_Predictor.git
